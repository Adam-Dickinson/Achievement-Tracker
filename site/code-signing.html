Code signing policy

Last updated 5 November 2026.

Who signs

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Until that is in place, installers are unsigned and Windows SmartScreen may warn when you run one.

What is signed

Only the installer, Trophy-Locker-Setup-<version>.exe, built from the public source in this repository. The build runs in GitHub Actions from a version tag, and the signing request comes from that same run. Nothing built on a personal computer is signed.

Roles

  • Author, committer, reviewer and approver of releases: Adam Dickinson.

The main branch and release tags are protected: changes need a pull request that passes the automated checks, and tags cannot be moved or deleted.

Privacy

Trophy Locker keeps your data on your computer. It has no accounts, no analytics and no crash reporting.

  • It contacts the game platforms you choose to connect (Steam, Xbox, PlayStation, Epic, Ubisoft, EA) to read your achievements, using the sign-in you gave it. Sign-in secrets are stored with Windows encryption.
  • It checks github.com for new versions at launch and every six hours. That sends only the usual details of a web request, such as your IP address, and nothing about your account, games or library. You can switch it off in Settings under Updates.
  • If you add a SteamGridDB key, it fetches artwork from SteamGridDB. The optional stream overlay is served only on your own computer.
