Local, private, anti-cheat safe

Your library stays in a database on your PC and sign-ins sit in the Windows keychain. It never touches game processes.

Up and running in a minute.

Installs for your user only, so no admin rights needed.

  1. Download the installer

    Grab the installer from the download button, or pick any version from the releases page.

  2. Let it past SmartScreen

    The installer isn't code-signed yet, so Windows may warn you the first time.

    If you see "Windows protected your PC", click More info, then Run anyway. The source code is public if you'd like to check it first.

  3. Connect your accounts

    Sign in to the platforms you play on. Your existing unlocks load quietly, and only new ones pop up. The app checks for updates and asks before downloading one.
