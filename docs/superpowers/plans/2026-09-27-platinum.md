# Platinum for every game: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Treat a game's own "unlock everything" achievement as its platinum, and award an app-made Platinum to games without one when they reach 100%, shown in Game detail, Activity, the Dashboard and toasts.

**Architecture:** A pure rule (`isPlatinumAchievement`) is applied wherever achievements are read or synced, so a game's own platinum is never stored. App-awarded platinums live in a new `platinum` table, written by the sync pass (announced when the pass announced an unlock) and by a silent startup pass. Screens get `platinum` flags, `appPlatinum` on entries, platinum items in Activity and a Dashboard count.

**Tech Stack:** TypeScript, `node:sqlite`, Vitest, React 19, Tailwind 4, motion.

**Spec:** [docs/superpowers/specs/2026-09-27-platinum-design.md](../specs/2026-09-27-platinum-design.md)

## Global Constraints

- SQL only in `src/main/store` (rule 8); schema change is a new `0006_platinum.sql` with an upgrade test.
- Baseline rule (rule 2): a first sync never announces; neither does the startup pass.
- No code comments; no hex colours in components (tokens in `styles/index.css`); Prettier style; ESLint zero warnings; strict TS, no `any`.
- Rule words and limits exactly as in the spec: 90 characters, up to four words between, filler `the other of your base main game regular story remaining`, after-words `in for of and from obtained completed have unlocked earned collected`.
- Stand-in achievement id `trophy-locker:platinum`, name `Platinum`, description `Every achievement in <game>`; headings `Platinum unlocked` (own) and `Platinum earned` (app).

### Task 1: The rule and the table

**Files:**
- Create: `src/main/store/platinum.ts`, `src/main/store/platinum.test.ts`, `src/main/store/migrations/0006_platinum.sql`
- Modify: `src/main/store/migrate.test.ts` (0006 upgrade)

**Interfaces (produces):**
- `isPlatinumAchievement(achievement: { readonly tier: string | null; readonly description: string | null }, gameTitle: string): boolean`
- `awardPlatinum(db: DatabaseSync, platformGameId: number, detectedAt?: Date): { earnedAt: Date | null } | null` (null when not awarded now)
- `awardPlatinums(db: DatabaseSync): number` (how many were awarded)
- `APP_PLATINUM_ID = 'trophy-locker:platinum'`, `appPlatinumAchievement(gameTitle: string): RemoteAchievement`

Migration:

```sql
CREATE TABLE platinum (
  platform_game_id INTEGER PRIMARY KEY REFERENCES platform_game(id),
  earned_at        TEXT,
  detected_at      TEXT NOT NULL
);
```
